    เพิ่ม Panthorium ใน ChatGPT
    
      
    ใช้ URL นี้สำหรับการเชื่อมต่อ MCP แบบ OAuth
    
      
    
      
    1. ใน ChatGPT เปิด Plugins แล้วเลือกเพิ่ม Custom MCP server
    2. ตั้งชื่อ Panthorium วาง URL ด้านบน และเลือกการยืนยันตัวตนแบบ OAuth
    3. เชื่อมบัญชีและตรวจสอบสิทธิ์ในหน้า Panthorium จากนั้นเลือกใช้ Panthorium ในบทสนทนา
    
      
    การเพิ่ม MCP server ขึ้นอยู่กับสิทธิ์และการตั้งค่าของบัญชีหรือพื้นที่ทำงาน ChatGPT ของคุณ
