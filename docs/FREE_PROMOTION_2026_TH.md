# บัญชีฟรี: โปรโมชันเสียงและข้อความ

- เริ่ม 18 ตุลาคม 2026 เวลา 00:00 น. และสิ้นสุดก่อน 1 ธันวาคม 2026 เวลา 00:00 น. เขตเวลา Asia/Bangkok
- Free ใช้เสียงเข้า/ออกและโทเคนข้อความเข้า/ออกได้ไม่จำกัดในช่วงนี้ รวมถึงบัญชีที่เคยใช้โควต้าหมดแล้ว
- ไม่หักโควต้าปกติหรือแพ็กเสริมที่ซื้อไว้ระหว่างโปรโมชัน บันทึกการใช้จริงแยกใน `promotion_*`
- เมื่อหมดโปรโมชัน เซิร์ฟเวอร์กลับสู่แพ็กเกจ Free ปกติทันทีตามเวลาของแต่ละคำขอ ไม่ต้องมี cron ไม่แก้แผนสมาชิก และไม่เก็บเงินอัตโนมัติ
- พื้นที่ ดาวน์โหลด แพ็กเกจที่ชำระเงิน การยืนยันตัวตน สิทธิ์ และการควบคุมอัตราคำขอยังคงเดิม
- API ส่ง `unlimited` รายชื่อสิทธิ์ พร้อม `remaining: null` สำหรับสิทธิ์นั้น ใช้ `catalog.hasQuota` ตรวจสิทธิ์ ห้ามตีความ null เป็นโควต้าหมด

# การสมัครโดยไม่บันทึกเสียง

หน้าลงทะเบียนใช้ OTP อีเมล รหัสผ่าน และยืนยันรหัสผ่าน แล้วเข้าสู่ระบบด้วยบัญชีถาวรได้เลยผ่าน `/api/auth/register/email` ไม่เรียกไมโครโฟนหรือบริการ Speaker Verification

ปิด `/api/auth/register/voice` โดยค่าเริ่มต้น (`voice_registration_paused`) เก็บการจัดการโปรไฟล์เสียงเดิมและการเข้าสู่ระบบตามเดิม การเปิด API สมัครเสียงอีกครั้งต้องตั้ง `PANTHORIUM_VOICE_REGISTRATION_ENABLED=1` โดยตั้งใจและคืน UI สมัครเสียงแยกต่างหาก

การทดสอบ: `node test/free-token-promotion.js`, `node test/email-registration.js`, `node test/email-registration-ui.js` และชุดทดสอบเดิมทั้งหมด ขั้นตอน deploy ตรวจไฟล์ UI, catalog โปรโมชัน, API สมัครอีเมลที่บังคับ OTP และการปิด API สมัครเสียงบน staging ทั้งสอง URL และ production candidate ก่อนรับ traffic
