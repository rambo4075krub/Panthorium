# ศูนย์การเงิน Panthorium

หน้าต่างและไอคอน “🏦 การเงินและชำระเงิน” สำหรับ administrator เท่านั้น ทั้ง API และคำสั่งเสียงตรวจบทบาท ผู้ใช้ทั่วไปและ operator เข้าไม่ได้

## หน้าต่าง

- ภาพรวม: ยอดรับชำระ คืนเงิน ค่าใช้จ่าย และยอดโอนเข้าธนาคาร แยกจากกัน
- รายการชำระ/คืนเงิน: เลขคำสั่งซื้อ แพ็กเกจ ยอด สถานะ และ charge อ้างอิง เปิด Dashboard Omise เพื่อดำเนินการคืนเงินจริง
- สมาชิกและโควตา: รายการสิทธิ์ล่าสุด 500 รายการ วันเริ่ม วันหมดอายุ ยอดใช้ และการเพิกถอน
- บัญชีรับ–จ่าย: รายการที่ตรวจและบันทึกพร้อมหลักฐาน เรียงตามวันจริงใน Asia/Bangkok
- ค่าใช้จ่าย: บันทึกยอดจากหลักฐานจริง เช่น ค่าธรรมเนียม Omise, Cloud และยอดโอนเข้าธนาคาร มี request key ป้องกันการส่งซ้ำและบันทึกผู้ดำเนินการ
- ข้อมูลผู้ประกอบการ: ชื่อ ที่อยู่ เลขผู้เสียภาษี อีเมล และชื่อกิจการ กรอกให้ครบก่อนส่งออก ชื่อ ที่อยู่ และอีเมลนี้แสดงในนโยบายสาธารณะ เลขผู้เสียภาษีไม่อยู่ใน API นโยบายสาธารณะ

## การตรวจรายการและรายงาน

กดตรวจรายการกับ Omise เพื่อดึงและยืนยัน charge จริงด้วย server key และ reconcile กับคำสั่งซื้อเดิม เงินสดรับบันทึกด้วย paid_at จริง ไม่ใช้วันสร้างคำสั่งซื้อแทน วันที่คืนเงินใช้ refund object ของ Omise มี unique source key ป้องกันซ้ำ ไม่รวม Test Mode

ช่วงวันที่ตรวจ Omise คือช่วงวันที่ **สร้างคำสั่งซื้อ** สูงสุด 500 รายการ หากมีคืนเงินคำสั่งซื้อเก่าให้ตรวจช่วงเดิมซ้ำก่อนออกรายงานสำหรับวันที่คืนเงินจริง ช่วงวันที่รายงานบัญชีคือวันที่รับ/คืน/จ่ายจริง เป็นคนละฐานกับรายการคำสั่งซื้อ ไม่มีการอ้างว่ารายงานครบจนกว่าจะตรวจเทียบ Omise และธนาคาร

ค่าธรรมเนียมไม่เดาจากเปอร์เซ็นต์ ให้บันทึกจากใบแจ้งหนี้จริง เงินโอนจาก Omise เข้าธนาคารไม่ใช่รายได้ซ้ำ รายงานนี้ไม่มีเครื่องมือยื่นแบบกรมสรรพากรและไม่คำนวณภาษีเงินได้หรือออกใบกำกับภาษี VAT

Excel เป็น .xlsx จริง มีข้อมูลผู้ประกอบการ เงินสดรับ–จ่าย และสรุปรายเดือน จำนวนเงินเป็นเซลล์ตัวเลข ข้อความเป็นเซลล์ string ป้องกัน formula injection PDF ใช้หน้าพิมพ์ A4 แนวนอน เลือก Save as PDF ในหน้าพิมพ์เบราว์เซอร์

รายการค่าใช้จ่ายในรุ่นนี้เป็นประวัติถาวร ยังไม่มีเครื่องมือแก้กลับรายการหรือแนบไฟล์หลักฐานในหน้าการเงิน เก็บเอกสารต้นฉบับแยกโดยอ้างอิงเลขที่เอกสาร

## นโยบาย

ฉบับ 2.0 วันที่ 14 ตุลาคม 2026 เป็นข้อความสำหรับผู้ใช้จริง ครอบคลุมผู้ให้บริการ บัญชี Gemini Live Voice Identity ความจำ ไฟล์ การชำระ ราคา ภาษี รอบสมาชิก การคืนเงิน และสิทธิข้อมูล ไม่มีข้อความ staging หรือคำอ้างว่าระบบลบทุกสำเนาอัตโนมัติ

ต้องกรอกที่อยู่กิจการและอีเมลติดต่อที่ต้องการประกาศในหน้าข้อมูลผู้ประกอบการก่อนเผยแพร่จริง และตรวจนโยบายการเก็บข้อมูล/การรับคำขอให้ตรงกับการปฏิบัติงาน ระบบไม่ได้เพิ่ม scheduled deletion หรือ account deletion อัตโนมัติจากการแก้ข้อความนโยบาย

## สิ่งที่ต้องทดสอบก่อน main

ตรวจ admin และหน้าผู้ใช้บน staging ทั้งสอง URL, ปฏิเสธสิทธิ์ guest/operator, บันทึกข้อมูลผู้ประกอบการและค่าใช้จ่ายด้วยฐานข้อมูลจริง, ดาวน์โหลด Excel และบันทึก PDF, ตรวจการชำระ/คืนเงินจริงหลัง Omise ปลดล็อก, เทียบยอดกับ Omise และธนาคาร
