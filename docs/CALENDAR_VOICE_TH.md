# ปฏิทินกับคำสั่งเสียง Sentinel

ผู้ใช้และแอดมินใช้ปฏิทินของบัญชีตนเอง เริ่มพูดผ่านไมค์ Sentinel หรือพิมพ์คำสั่งเดียวกัน ระบบใช้วันเวลาปัจจุบันในบริบท และต้องถามเมื่อเวลา/ชื่อนัดหมายยังไม่ชัดเจน

| สิ่งที่ทำ | ตัวอย่างคำสั่ง |
|---|---|
| เปิด ปิด ย่อ ขยาย รีเฟรช | เปิดปฏิทิน / ขยายปฏิทินเต็มจอ |
| เลื่อนเดือน กลับวันนี้ | ปฏิทินเดือนหน้า / ปฏิทินเดือนก่อน / ปฏิทินวันนี้ |
| เลือกวันหรือเดือน | ไปวันที่ 25 ตุลาคม 2569 / เปิดปฏิทินมกราคมปีหน้า |
| อ่านและสรุปตาราง | พรุ่งนี้มีนัดอะไร / สรุปตารางสัปดาห์หน้า |
| ค้นหา | ค้นหานัดหมอเดือนนี้ / ค้นหานัดที่ห้องประชุมหนึ่ง |
| เพิ่มนัดพร้อมเวลาจบและสถานที่ | เพิ่มประชุมพรุ่งนี้ 9 ถึง 10 โมง ที่ห้องหนึ่ง |
| แก้ไขและเลื่อนเวลา | เลื่อนนัดประชุมเป็น 11 โมง / เปลี่ยนสถานที่ประชุม |
| นัดหมายซ้ำ | เพิ่มนัดทุกวันจันทร์ 9 ถึง 10 โมง จำนวน 4 ครั้ง |
| เปลี่ยนเฉพาะครั้งหรือทั้งชุด | เลื่อนเฉพาะครั้งวันที่ 25 / ลบนัดซ้ำทั้งชุด |
| ตรวจเวลาชน | ตรวจนัดหมายที่เวลาชนกันสัปดาห์หน้า |
| หาช่วงว่าง | พรุ่งนี้ 9 ถึง 17 โมง มีช่วงว่าง 1 ชั่วโมงเมื่อไร |
| ตั้ง/ยกเลิกเตือน | เตือนก่อนนัดหมอ 30 นาที / ยกเลิกการเตือนนัดหมอ |

คำสั่งเปิดดูไม่เปลี่ยนข้อมูล การสร้าง แก้ไข ลบ หรือตั้งเตือนจะแสดงรายละเอียดให้ยืนยันก่อนดำเนินการ ใช้รหัสนัดหมายและชื่อที่อ่านจากบัญชีจริง ไม่เลือกนัดจากชื่อคล้ายกันเอง

นัดซ้ำเก็บเป็นชุดวันที่ระบุชัด สูงสุด 52 ครั้งต่อชุด การเลื่อนทั้งชุดต้องส่งวันที่ใหม่ครบชุด ไม่ใช่นัดซ้ำแบบไม่สิ้นสุด การแก้หรือลบเฉพาะครั้งใช้อ้างอิงครั้งนั้นแยกจากทั้งชุด

การหาช่วงว่างและเวลาชนอาศัยเวลาจบของนัดหมาย หากไม่มีเวลาจบหรือข้อมูลถูกตัด ระบบต้องแจ้งว่าข้อมูลไม่พอ ห้ามยืนยันว่าเวลาว่างจากข้อมูลไม่ครบ ปฏิทินอ่านรายการต้นทางได้สูงสุด 10,000 รายการ และแจ้งเมื่อถึงขอบเขต เครื่องมือคืนรายการครั้งละไม่เกิน 100 พร้อม total/truncated และขอบเขตเวลา

การเตือนเป็นอีเมลไปบัญชีที่ยืนยันแล้ว แยกจากนัดหมาย: การเลื่อน/ลบนัดไม่ได้เลื่อน/ยกเลิกเตือนเดิมอัตโนมัติ ต้องสั่งและอนุมัติแยก รองรับเตือนซ้ำรายวัน/สัปดาห์แบบจำกัดจำนวนตามระบบเตือนเดิม ไม่ได้ส่งคำเชิญผู้เข้าร่วม หรือซิงก์กับ Google Calendar
