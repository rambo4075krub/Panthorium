# หน้าต่างบัญชีใน Start Menu

แยกลงทะเบียน เข้าสู่ระบบ/ลืมรหัสผ่าน และออกจากระบบออกจากหน้าต่าง Voice Identity ผู้ใช้เปิดแต่ละหน้าจากรายการ Start Menu ได้โดยตรง ปุ่มบัญชีเดิมใน footer ซ่อนไว้เพื่อไม่ซ้ำกับรายการใหม่

การลงทะเบียนยังใช้ระบบเดิม: ยืนยันอีเมลด้วย OTP ตั้งและยืนยันรหัสผ่าน พร้อมบันทึกเสียง 3–5 ช่วงและความยินยอมก่อนสร้างบัญชีผ่าน `/api/auth/register/voice` ไม่ได้เปลี่ยนเป็นการสมัครโดยไม่ตรวจเสียง หน้าต่างนี้มี ID `account-register` แยกจาก `voice-identity`

`account-login` ใช้ `/api/auth/login` และมีฟอร์มขอ OTP/รีเซ็ตรหัสผ่านเดิม รวมถึงตัวเลือกจำรหัสผ่าน/เซสชันที่ผู้ใช้เลือกเอง เมื่อเปลี่ยนบัญชีหรือล็อกเอาต์จะทิ้งหน้าต่างและค่ารหัสผ่าน/OTP เดิม `account-logout` แสดงหน้าต่างแยกและเรียก logout เมื่อผู้ใช้กดปุ่มในหน้าต่างนั้น

Voice Identity แสดงรายการเสียงและการทดสอบ/จัดการเสียง สำหรับ Guest ที่ยังไม่ได้สมัครจะแสดงวิธีไปเมนูลงทะเบียน ไม่แสดงอีเมล รหัสผ่าน เข้าสู่ระบบ หรือฟอร์มกู้รหัสผ่านในหน้าต่างเสียง

ทดสอบด้วย `node test/account-ui.js`, `node test/voice-windows.js`, `npm test` และ `npm run check` จากนั้นตรวจหน้า Guest และหน้า admin บน Google staging ก่อนส่ง main

การรับเงิน Omise ยังไม่เปิดใช้ ต้องตั้งค่ากุญแจฝั่งเซิร์ฟเวอร์และทำ durable billing ledger พร้อมตรวจการชำระเงินจริงและบังคับสิทธิ์/โควต้า ก่อนปลดล็อก checkout ตาม `docs/BILLING_UI_TH.md`

Voice Identity อยู่ในหน้าลงทะเบียนเดียวกัน ไม่แสดงไอคอนแยกใน Start Menu ผู้ใช้ที่มีบัญชีแล้วเปิดหน้าเดียวกันเพื่อจัดการเสียงได้ โดยไม่สร้างบัญชีใหม่
