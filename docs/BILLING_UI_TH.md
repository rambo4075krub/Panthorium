# หน้าแพ็กเกจและชำระเงิน Panthorium

เปิดจาก Start Menu → 💳 แพ็กเกจและชำระเงิน มีสมาชิก เสียงเพิ่ม ข้อความเพิ่ม และพื้นที่/ดาวน์โหลด พร้อมหน้าสรุปยอดก่อนชำระ ใช้ window manager เดิมเพื่อปิด ย่อ และเปิดกลับได้

## เกณฑ์ราคา

ยึด PDF วันที่ 11 ตุลาคม 2569 สถานะบุคคลธรรมดาไม่จด VAT: Free 0, Life 189, Work 489, Work Pro 1,089 บาท เสียงเสริม 59/169/399/849 ข้อความเสริม 29/99/249/499 พื้นที่รายเดือน 49/129/279/499 ดาวน์โหลด 10 GiB 99 บาท ดูโควต้าทั้งหมดใน `billing-catalog.js` ซึ่งใช้ร่วมกันระหว่าง UI และ server

## ขอบเขตฉบับนี้

สร้างหน้าเลือกแพ็กเกจ หน้าสรุปรายการ และไอคอนเท่านั้น ยังไม่รับเงินจริง ไม่สร้างคำสั่งซื้อ ไม่ให้สิทธิ์บัญชี และไม่เปิดให้สมาชิกต่ออายุ ปุ่มชำระปิดอยู่เสมอ การแสดงราคาไม่ยืนยันว่าการคุมโควต้าใน AI/Cloud Files ทำแล้ว

`GET /api/billing/catalog` เปิดอ่านรายการสินค้าได้ `POST /api/billing/checkout` ต้องยืนยันตัวตน บล็อก guest และตอบ `503 checkout_not_configured` สำหรับรายการซื้อที่ถูกต้อง ยังไม่มีการเรียก Omise การส่งราคา/สถานะ paid จาก client ไม่ทำให้เกิดสิทธิ์ ไม่มี Secret Key หรือข้อมูลบัตรใน UI

## งานก่อนเปิดชำระเงินจริง

1. ตรวจสถานะ Omise Live และค่าธรรมเนียมจริง แยก Test key ของ staging จาก Live key ของ production เก็บ secret ฝั่ง server
2. เพิ่ม durable order/subscription/entitlement ledger และการเปลี่ยนสถานะพร้อม transaction ป้องกันสมาชิกซ้อนข้ามช่องทางและการเติมโควต้าซ้ำ
3. Backend รับ productId และคำนวณราคาเอง ตรวจบัญชียืนยันแล้วและสมาชิก Life ขึ้นไปสำหรับพื้นที่/ดาวน์โหลด แสดงยอด prorate ก่อนซื้อกลางรอบ
4. เชื่อมการรับเงิน Omise และตรวจรายการกับ API โดยไม่ให้สิทธิ์จาก return URL หรือ frontend ตรวจจำนวนเงิน สกุลเงินและเจ้าของ order พร้อม idempotency รองรับ callback ซ้ำ/สลับลำดับ
5. กำหนดและแสดงเงื่อนไขต่ออายุ ยกเลิก คืนเงิน รอบบิล และอายุแพ็กก่อนยืนยันการซื้อ พร้อมใบเสร็จตามสถานะผู้ขาย
6. บังคับโควต้ารวมทุกอุปกรณ์จาก server รวม retry/background/context/transcription และต้นทุนจริง ก่อนเปิดขาย Text เดี่ยวต้องตรวจว่าผลตอบ Live ใช้โควต้าเสียงหรือไม่
7. Android ใช้ Play Billing พร้อม server verification และ notifications ก่อนเปิดการซื้อในแอป ฉบับนี้ปิดปุ่มเลือกซื้อบน native Capacitor ไม่ใช้ Omise จ่ายในแอป
8. ทดสอบ staging ทั้งหน้าผู้ใช้และ admin ก่อน main: จ่ายสำเร็จ/ล้มเหลว/ค้าง ต่ออายุ ยกเลิก คืนเงิน webhook ซ้ำ หมดอายุ และโควต้าข้ามอุปกรณ์

ตรวจฉบับนี้ด้วย `node test/billing-ui.js` และ `npm run check` ไม่ถือว่าผ่านการทดสอบรับเงินจริง
