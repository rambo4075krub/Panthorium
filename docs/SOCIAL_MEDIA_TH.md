# Social Media ใน Panthorium

หมวด Start → Social Media ใช้ได้ในหน้า User และ Admin สำหรับบัญชีที่เข้าสู่ระบบและมีสิทธิ์ chat ข้อมูลใช้งานจริงเก็บใน PostgreSQL; production ไม่ fallback ไปข้อมูลจำลองในหน่วยความจำ

Social Media ใช้หน้าต่างเดียว สลับเมนูแล้วเก็บร่างและสถานะของแต่ละแท็บไว้ แถบเมนูอยู่ใต้กรอบหน้าต่างโดยไม่มีหัวเรื่องซ้ำ เรียง **Watch → Short → Live → Market → Community → Talk → Connect → Profile → Add Friends → Refresh** เลื่อนแถบแนวนอนได้บนจอเล็ก และใช้ลูกศรซ้าย/ขวาหรือ Home/End เปลี่ยนแท็บได้

| เมนู | การทำงาน |
|---|---|
| Watch | โพสต์ภาพ PNG/JPEG/WebP/GIF และข้อความ เลือกสาธารณะหรือเพื่อน แสดงภาพ/GIF ทันที ถูกใจและความคิดเห็นพร้อมจำนวน เมนูสามจุดสำหรับจัดการโพสต์ |
| Short | วิดีโอสั้น/ยาว หรือ Reels แบบ MP4/WebM ความคิดเห็น ถูกใจ และเพลย์ลิสต์ส่วนตัว วิดีโอ Watch เดิมแสดงที่นี่โดยคงรหัส ความคิดเห็น และสิทธิ์เดิม |
| Live | ถ่ายทอดกล้อง/เสียงสดผ่าน WebRTC แชตและการออกจากห้อง |
| Market | ร้านค้าสาธารณะ ลงสินค้า ราคา สต็อก และคำขอสั่งซื้อ ป้องกันขายเกินจำนวนและคำขอซ้ำ |
| Community | กลุ่มเปิดหรือปิด แชต รูป วิดีโอและไฟล์เฉพาะสมาชิก กลุ่มปิดต้องให้ผู้สร้างอนุมัติ |
| Talk | แชตส่วนตัว ไฟล์ โทรเสียง/วิดีโอ เพื่อนที่ตอบรับแล้วเริ่มสนทนาได้ทันที บุคคลอื่นยังต้องรับคำขอสนทนา |
| Connect | สมัครใจเปิดใช้สำหรับผู้ใหญ่ ซิงค์ชื่อ รูป และคำแนะนำจาก Profile เมื่อเลือกยินยอม หรือใช้ชื่อแยก เลือกเพศและความสนใจส่วนตัว ชาย–ชาย ชาย–หญิง หญิง–หญิง หรือตัวเลือกอื่น สนใจตรงกันจึงสนทนา/โทรใน Connect |
| Profile | โปรไฟล์และรูปดูได้เฉพาะเจ้าของ เลือกให้ผู้อื่นค้นหาเฉพาะชื่อและส่งคำขอเพื่อนได้ ชื่อยังใช้กำกับโพสต์/ข้อความ |
| Add Friends | ค้นหาเพื่อน ส่ง/ยกเลิกคำขอ รับ/ปฏิเสธคำขอ รายชื่อเพื่อน เลิกเป็นเพื่อน และบล็อก |
| Refresh | โหลดข้อมูลใหม่เฉพาะเมนูที่กำลังเปิด |

“สาธารณะ” ในระบบปัจจุบันหมายถึงผู้ใช้ที่เข้าสู่ระบบ API ยังคงตรวจบัญชีและสิทธิ์ ไม่เปิดไฟล์ส่วนตัวให้ผู้ไม่เข้าสู่ระบบ โพสต์ Community เดิมที่ไม่ใช่โพสต์ในกลุ่มแสดงใน Watch หรือ Short ตามชนิดสื่อโดยคงสิทธิ์เดิม

## เริ่มใช้
1. เปิด Start → Social Media → Profile บันทึกชื่อ รูป และข้อมูลของคุณ เลือกได้ว่าจะให้ค้นหาชื่อหรือไม่
2. Watch ใช้ภาพและข้อความ ส่วน Short ใช้วิดีโอ จาก Creative Studio กดแชร์จะเปิดร่างในเมนูที่เหมาะสม เอกสารเปิด Community ให้เลือกกลุ่มก่อนส่ง
3. ค้นหาเพื่อนใน Add Friends แล้วส่งคำขอ หลังตอบรับกด “ส่งข้อความ” เพื่อเปิด Talk ในหน้าต่างเดียวกัน การโทร/ไลฟ์ขอสิทธิ์อุปกรณ์เมื่อผู้ใช้เริ่มเท่านั้น
4. แต่ละเมนูมีตัวเลขยังไม่อ่านและส่วน “กิจกรรมในเมนูนี้” เปิดรายการหรือทำเครื่องหมายว่าอ่านแล้วได้ ไม่มีปุ่มแจ้งเตือนรวม การอ่านแจ้งเตือนไม่ทำให้ข้อความในแชตเป็นอ่านแล้ว การสลับไปแท็บอื่นไม่อ่านแชตที่ซ่อนอยู่
5. เครื่องมืออยู่เฉพาะเมนูที่เกี่ยวข้อง เช่น เพลย์ลิสต์ใน Short คำสั่งซื้อใน Market บัญชีที่บล็อกใน Profile/Add Friends และตั้งค่าจับคู่ใน Connect
6. Connect ให้ผู้ใช้เลือกซิงค์โปรไฟล์และยืนยันอายุ/ความยินยอมก่อนเปิดใช้ เพศและการตั้งค่าความสนใจไม่ส่งให้ผู้อื่นในผลค้นหา/API การแก้ Profile ซิงค์เฉพาะบัญชีที่เปิดตัวเลือกนี้ ปิด Connect แล้วหยุดการค้นพบและการเข้าถึงบทสนทนา
7. การเปิดผ่าน Start เมนูเสียง ลิงก์ตรง Creative Studio และแชตติดต่อแอดมิน ใช้หน้าต่าง Social Media เดียวกัน คำสั่งแก้ไขผ่าน social.write ยังต้องอนุมัติรายละเอียดก่อน

## โพสต์ Watch

- หน้าสร้างโพสต์มีรายละเอียด รูป/GIF และตัวเลือก **ผู้ที่ดูได้: สาธารณะ / เพื่อน** ไม่มีช่องชื่อเรื่อง กด **เผยแพร่** เพื่อส่ง หรือ **ยกเลิก** ด้านขวาเพื่อกลับฟีดโดยไม่เผยแพร่
- “เพื่อน” หมายถึงบัญชีที่ตอบรับเป็นเพื่อนแล้ว ผู้ติดตามหรือคำขอที่ยังไม่ตอบรับเปิดโพสต์ รูป และความคิดเห็นไม่ได้ เลิกเป็นเพื่อนหรือบล็อกแล้วสิทธิ์สิ้นสุดในการเรียกข้อมูลครั้งถัดไป
- รูปและ GIF แสดงในโพสต์อัตโนมัติ รวมถึงโพสต์ Community เดิมที่ย้ายมา Watch ไม่แสดงชื่อไฟล์ ปุ่มเปิดไฟล์/ดูตัวอย่าง หรือปุ่มดาวน์โหลดต้นฉบับ
- แถวล่างมีถูกใจ **ความคิดเห็น N** และ **⋯** ชิดขวา กดความคิดเห็นเพื่อเปิด/ซ่อนรายการและช่องเขียน จำนวนรวมครอบคลุมทุกหน้า ไม่นับความคิดเห็นที่ลบ ซ่อน หรือถูกบล็อก
- ใต้ช่องเขียนมี **ส่ง** และ **ลบ** สำหรับล้างข้อความที่ยังไม่ส่ง ความคิดเห็นที่ส่งแล้วของตนมีปุ่ม **ลบความคิดเห็น** พร้อมยืนยันก่อนลบ การกดถูกใจหรือเปิด/ซ่อนความคิดเห็นไม่ทำให้ร่างข้อความหาย
- เมนู **⋯** รวมแก้ไข/ลบสำหรับผู้โพสต์ และขอสนทนา/บล็อก/รายงานสำหรับผู้ชม พร้อมนำไปใช้กับ Sentinel คัดลอกลิงก์ และนำไปวางแผนในปฏิทิน

## รูปแบบร่วมใน Short, Live และ Market

ทั้งสามหน้าใช้แถวถูกใจ/ความคิดเห็นพร้อมจำนวนและเมนู **⋯** เช่นเดียวกับ Watch ความคิดเห็นเริ่มแบบซ่อน กดเพื่อเปิดช่องส่ง/ล้างร่าง และลบความคิดเห็นของตนได้ สื่อแสดงในรายการโดยไม่มีชื่อไฟล์ ปุ่มเปิดตัวอย่าง หรือปุ่มดาวน์โหลดต้นฉบับ ฟอร์มสร้างและแก้ไขมีปุ่ม **ยกเลิก** ชิดขวา

- **Short** แสดงเครื่องเล่นวิดีโอในโพสต์พร้อมปุ่มเล่น ไม่เล่นเสียงอัตโนมัติ การกดถูกใจคงเครื่องเล่นและร่างความคิดเห็นไว้ ไม่มีช่องชื่อเรื่องตอนสร้างโพสต์ คำสั่งเพลย์ลิสต์อยู่ในเมนูสามจุด
- **Market** คงชื่อสินค้า ราคา สต็อก และปุ่มส่งคำขอสั่งซื้อ ช่องชื่อเรียกว่า **ชื่อสินค้า**
- **Live** คงชื่อไลฟ์ ปุ่มเข้าชม และตัวควบคุมการถ่ายทอดสด ความคิดเห็นใช้แชตสดเดิม ต้องเข้าชมก่อนส่ง เมื่อเปิดความคิดเห็นจะโหลดข้อความใหม่เป็นระยะโดยคงร่างไว้ เมนูสามจุดของผู้ถ่ายทอดมี **จบไลฟ์**
- ทั้งสามหน้ายังคงเผยแพร่สาธารณะตามประเภทเมนู ตัวเลือกสาธารณะ/เพื่อนในการสร้างโพสต์อยู่ที่ Watch

## กลุ่ม Community

1. เปิด Community จะแสดง **กลุ่มของฉัน** เฉพาะกลุ่มที่เป็นสมาชิก มี **กลุ่มทั้งหมด** สำหรับค้นหา/เข้าร่วม และ **สร้างกลุ่ม** สำหรับใส่ชื่อ คำอธิบาย และเลือกประเภท ทั้งสามเมนูเปิด/พับเนื้อหาด้านล่างในหน้าต่างเดิม
2. **แบบเปิด** เข้าร่วมได้ทันที ส่วน **แบบปิด** ต้องส่งคำขอและรอผู้สร้างอนุมัติ ผู้สร้างเห็นรายชื่อและวันที่ขอ พร้อมปุ่มอนุมัติ/ไม่อนุมัติ ผู้ขอสามารถยกเลิกคำขอได้
3. ชื่อ คำอธิบาย ประเภท และจำนวนสมาชิกแสดงในรายการกลุ่ม แต่แชต โพสต์ และไฟล์ดูได้เฉพาะสมาชิก ทั้งกลุ่มเปิดและปิด กลุ่มเดิมที่ยังไม่มีประเภทถือเป็นกลุ่มเปิด
4. สมาชิกพิมพ์แชต แนบรูป/วิดีโอ/ไฟล์จากคลาวด์ หรืออัปโหลดแล้วกด **ส่ง** ได้ รูปและวิดีโอแสดงในแชต มีปุ่มดาวน์โหลดต้นฉบับ ไฟล์ใช้โควต้าบัญชีเจ้าของตามเดิม
5. แสดงชื่อผู้ส่ง วันที่/เวลา ✓ เมื่อส่งแล้ว และ ✓✓ พร้อมจำนวนคนที่อ่านเมื่อสมาชิกเห็นข้อความจริง ประวัติเก่ามีปุ่มโหลดข้อความก่อนหน้า โพสต์เดิมยังอยู่ในส่วน “โพสต์ในกลุ่ม”
6. คำขอเข้ากลุ่ม ผลอนุมัติ/ไม่อนุมัติ และข้อความใหม่แสดงใน **กิจกรรมในเมนูนี้** ของ Community พร้อมตัวเลขยังไม่อ่าน การอ่านแจ้งเตือนไม่เท่ากับการอ่านข้อความ
7. กลุ่มมีสมาชิกได้สูงสุด 200 คน ผู้สร้างยังคงอยู่เพื่อดูแลกลุ่ม สมาชิกที่ออกจากกลุ่มจะไม่มีสิทธิ์เปิดแชตหรือไฟล์ผ่านระบบอีก กลุ่มปิดต้องขออนุมัติใหม่หากกลับเข้าร่วม

## พื้นที่และสิทธิ์
ไฟล์อัปโหลดใช้ Cloud Files ของเจ้าของบัญชีและโควต้าเดิมจากแพ็กเกจ ไม่มี bucket ฟรีแยกเพื่อเลี่ยงโควต้า โพสต์/ข้อความอ้างอิง file ID เดิม ไม่ทำสำเนาต่อผู้ชม การดาวน์โหลดต้นฉบับนับโควต้าดาวน์โหลดของผู้ดาวน์โหลด ไฟล์ทุกครั้งตรวจว่าผู้อ่านเห็นรายการและผู้ส่งเป็นเจ้าของไฟล์จริง

ขนาดต่อไฟล์ปัจจุบันตาม Files คือ 20 MB แนบได้ 6 ไฟล์ต่อรายการ งานใหญ่กว่านี้ยังต้องพัฒนาการอัปโหลดแบบแบ่งส่วนเพิ่มเติม ลบโพสต์ไม่ลบไฟล์ต้นฉบับ; ลบไฟล์จาก Files แล้วโพสต์ที่อ้างอิงจะเปิดไฟล์นั้นไม่ได้ ข้อความ โปรไฟล์ รายการซื้อขาย และสิทธิ์เป็น metadata ในฐานข้อมูล ไม่ใช่สำเนาไฟล์ในพื้นที่ผู้ชม

บล็อกมีผลทั้งสองทิศทางต่อการค้นหา อ่านโพสต์ ข้อความและสัญญาณโทร; เปลี่ยนผู้ชม/ออกกลุ่ม/ปิด Connect/ซ่อนโดยแอดมินมีผลต่อการอ่านและไฟล์ครั้งถัดไป ข้อมูลที่ผู้รับดาวน์โหลดไปแล้วไม่สามารถเรียกคืนจากอุปกรณ์เขาได้ โปรไฟล์ไม่แสดงอีเมลบัญชี

## ขอบเขตการโทร ไลฟ์ และร้านค้า
- WebRTC ใช้ peer-to-peer และสัญญาณในฐานข้อมูล รองรับการทำงานหลาย Cloud Run instance โดยไม่ตั้ง inference standby
- Live รุ่นนี้มีผู้ชมพร้อมกันสูงสุด 8 คนต่อห้อง เพื่อจำกัดการส่งวิดีโอจากเครื่องผู้ถ่ายทอด ไม่ใช่ระบบกระจายสัญญาณขนาดใหญ่แบบ SFU/CDN และยังไม่มีบันทึกไลฟ์อัตโนมัติ
- เครือข่ายที่ต่อโดยตรงไม่ได้ต้องตั้ง `SOCIAL_TURN_URLS` (รายการ turn:/turns: คั่นด้วย comma) และ `SOCIAL_TURN_SECRET` ของ TURN ที่รองรับ REST shared-secret credentials บริการออก credential อายุหนึ่งชั่วโมงให้บัญชีที่เข้าห้องได้ ไม่ส่ง shared secret ไปเบราว์เซอร์ การไม่มี TURN แสดงข้อความตามจริง ไม่อ้างว่าทุกเครือข่ายใช้งานได้
- Social Media แจ้งเตือนคำขอสนทนา ข้อความ และกิจกรรมกลุ่มขณะเปิด Panthorium แม้ไม่ได้เปิด Talk; ยังไม่มี push notification เมื่อปิด Panthorium Browser
- Market เป็นการลงสินค้าและจัดการคำขอสั่งซื้อ ยังไม่มีการตัดเงิน เอสโครว์ จ่ายเงินผู้ค้า หรือระบบขนส่ง การชำระค่าแพ็กเกจ Panthorium เดิมไม่ได้ถูกนำมาอ้างเป็น marketplace settlement
- Connect ใช้การยืนยันอายุด้วยตนเอง ไม่ใช่บริการตรวจเอกสารอัตลักษณ์อัตโนมัติ
- ค้นหา/ฟีดอ่านเป็นหน้า 100 รายการ (มี cursor) และเพลย์ลิสต์/กลุ่มจำกัด 200 รายการหรือสมาชิกต่อชุด

## การทดสอบ
ชุดบริการใช้กับ repository ในหน่วยความจำสำหรับทดสอบและ PostgreSQL จริงใน schema ชั่วคราว ครอบคลุมการแยกบัญชี ไฟล์ส่วนตัว เปลี่ยนผู้ชม บล็อก ยอมรับคำขอ สนใจตรงกัน กลุ่ม เพลย์ลิสต์ สต็อกพร้อมกัน idempotency และสิทธิ์ผู้ดูแล

CI เพิ่ม Chromium สองบัญชี ใช้กล้อง/ไมค์จำลองเพื่อพิสูจน์การส่ง audio/video จริงผ่าน RTCPeerConnection และทางเดินสัญญาณของ API ทดสอบวางสาย ไลฟ์ และผู้ชมไม่เปิดกล้อง ผลนี้ไม่ใช่การรับรองไมค์เครื่องผู้ใช้หรือทุกเครือข่าย NAT/TURN

ชุดทดสอบกลุ่มใช้ทั้งหน่วยความจำและ PostgreSQL ครอบคลุมคำขอ/อนุมัติพร้อมกัน การกันบุคคลภายนอก การถอนสิทธิ์หลังออกกลุ่ม การอ่านแยกตามสมาชิก และการแจ้งเตือน ส่วน Chromium สามบัญชีทดสอบสร้างกลุ่มทั้งสองแบบ อนุมัติ แชต อัปโหลด/แสดงรูปและวิดีโอ ดาวน์โหลดไฟล์ โควต้าคลาวด์เดิม หน้าจอมือถือ ประวัติแชต และการรักษาร่างข้อความ/วิดีโอขณะอัปเดต

Deployment ตรวจ shell User/Admin, เนื้อหาไฟล์ UI/RTC ตรงกับ release และ API ปฏิเสธผู้ไม่เข้าสู่ระบบ โดยไม่สร้างโพสต์สาธารณะหรือส่งข้อความหาผู้ใช้จริงเพื่อทดสอบ

ชุดทดสอบปรับหน้าต่างครอบคลุมคำขอเพื่อน โปรไฟล์/ไฟล์ส่วนตัว การซิงค์ Connect แบบยินยอม การจับคู่ตามความสนใจร่วม การแยก Talk/Connect การคงรหัสวิดีโอเดิม และ pagination แจ้งเตือนแยกเมนูทั้งหน่วยความจำ/PostgreSQL ส่วน Chromium ทดสอบเก้าแท็บในหน้าต่างเดียว ร่างข้อความ เมนูเสียง คำขอเพื่อนจริงระหว่างบัญชีทดสอบ การไม่อ่านข้อความในแท็บที่ซ่อน และจอ 320/390 พิกเซล

ชุดทดสอบ Watch ใช้ Chromium สามบัญชีตรวจสื่อ/GIF แบบแสดงทันที เมนูสามจุด การเปิด/ซ่อนความคิดเห็น ส่ง ล้างร่าง ลบความคิดเห็นของตน การคงร่างขณะถูกใจ และการสร้าง/ยกเลิก/แก้ไขผู้ชมบนจอเดสก์ท็อปและมือถือ ส่วนหน่วยความจำ/PostgreSQL ตรวจสิทธิ์เพื่อนถึงไฟล์และความคิดเห็น รวมถึงจำนวนความคิดเห็นเกิน 100 รายการ

ชุดทดสอบรูปแบบร่วมครอบคลุมเครื่องเล่น Short ที่ไม่ถูกสร้างใหม่ขณะถูกใจ คำขอสั่งซื้อ Market และการเริ่ม/ยกเลิก/เข้าชม Live ผ่านหน้าจอจริง พร้อมแชตสด ลบแชตของตน อัปเดตจำนวนโดยคงร่าง และจบไลฟ์จากเมนูสามจุด


## เมนูและการสนทนา (20 ตุลาคม 2026)

- Watch/Short ไม่มีปุ่มเครื่องมือที่เชื่อมงานหรือรายการทั้งหมด ส่วน Market เอาออกเฉพาะเครื่องมือที่เชื่อมงาน คำสั่งในเมนูสามจุดของโพสต์ยังใช้ได้
- Talk แสดงชื่อคู่สนทนาและตัวอย่างข้อความล่าสุด เรียงตามความเคลื่อนไหว แสดงข้อความรับทางซ้ายและข้อความส่งทางขวา คงวันเวลาและเครื่องหมายส่ง/อ่าน ไม่มีปุ่มลบข้อความ ปุ่ม **กลับ** อยู่ขวาของแถว **ส่ง** เพื่อกลับรายการแชต
- ข้อความ Talk รวมถึงแชตติดต่อแอดมินหมดอายุ 72 ชั่วโมงหลังส่ง เซิร์ฟเวอร์ปฏิเสธการอ่าน ดาวน์โหลด และรับทราบการอ่านทันทีเมื่อหมดอายุ และไม่นำข้อความนั้นมาแสดงในตัวอย่างหรือแจ้งเตือน การล้างข้อมูลทำเมื่อเริ่มบริการ ในงาน `/internal/jobs/tick` และระหว่างการอ่าน/เขียน/โหลดแจ้งเตือนโดยจำกัดรอบหนึ่งนาที ลบทั้งข้อความ แจ้งเตือน และเนื้อหาในสำเนาคำขอส่งซ้ำ โดยเก็บเพียงผลยืนยันหมดอายุเพื่อไม่ให้การส่งซ้ำสร้างข้อความเดิมขึ้นใหม่ ไฟล์ต้นฉบับของเจ้าของใน Files และข้อความ Community/Connect ไม่อยู่ในนโยบายนี้
- ตั้งค่า Connect มี **กลับ** ชิดขวาแถว **บันทึก** หน้าบัญชีที่บล็อกของ Profile มี **กลับ** ชิดขวาไปหน้าโปรไฟล์ และ Add Friends เรียง **ค้นหาเพื่อน → บัญชีที่บล็อก**
- ทดสอบความสอดคล้องในหน่วยความจำ/PostgreSQL สำหรับการหมดอายุ สิทธิ์ไฟล์ สำเนาการส่งซ้ำ รายชื่อกลุ่ม และ pagination แชต ส่วน Chromium ตรวจปุ่ม การกลับหน้า การจัดข้อความบนจอ 320/390 พิกเซล การอัปเดตตัวอย่างโดยไม่ทำเครื่องหมายอ่าน และการคงร่างระหว่างลบข้อความหมดอายุ
